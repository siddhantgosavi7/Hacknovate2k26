> Transforming Citizens into Smart Recyclers using AI.

EcoSort AI is an AI-powered smart waste management platform designed to improve waste segregation, recycling awareness, and sustainability through intelligent waste classification and gamified citizen engagement.

Built for hackathons, smart city innovation, and sustainable urban ecosystems.

---

## 🚀 Features

### 🧠 AI Waste Scanner
- Upload or scan waste images
- AI-based waste classification
- Confidence score prediction
- Smart disposal guidance

### ♻️ Smart Segregation Guide
- Wet/Dry waste identification
- Recyclable detection
- Hazardous waste alerts
- Eco-friendly disposal instructions

### 🏆 EcoScore Rewards
- XP & EcoScore system
- Recycling streak tracking
- Achievement badges
- Sustainability leaderboard

### 📊 Municipality Analytics Dashboard
- Waste distribution analytics
- Recycling participation trends
- CO₂ savings insights
- Smart city statistics

### 🤖 AI Sustainability Chatbot
- Recycling guidance
- Waste disposal FAQs
- Smart sustainability assistance

### 🚛 Pickup Scheduling
- Schedule waste pickups
- Track pickup requests
- Waste category selection

### 🌍 Community Sustainability
- Society rankings
- College competitions
- Green challenges & badges
